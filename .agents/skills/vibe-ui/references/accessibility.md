# Vibe UI Accessibility

Required:
- skip navigation link;
- semantic landmarks and headings;
- keyboard reachable controls;
- visible focus indication;
- accessible names for icon-only controls;
- dialogs/sheets restore focus;
- tables expose headers and row/column semantics;
- graph controls expose state and purpose without relying on color;
- selected/truncated/error states use text or icons in addition to color;
- responsive layouts must not trap keyboard focus or create inaccessible horizontal overflow;
- theme changes must preserve contrast and focus visibility.

Test targets: 360px, 768px and 1440px.
