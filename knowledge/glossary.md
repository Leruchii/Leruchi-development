# Glossary

- **Vibe / VibePlatform** — graph-native developer platform on PostgreSQL.
- **AGE** — Apache AGE, the PostgreSQL graph extension; an implementation detail.
- **pgvector** — PostgreSQL vector extension.
- **RLS** — PostgreSQL row-level security.
- **Query IR** — Vibe's intermediate representation of graph queries.
- **Schema Catalog** — authoritative registry of graph metadata.
- **service_role** — privileged role that bypasses RLS; never given to AI agents unrestricted.
- **MCP** — Model Context Protocol integration.
- **GraphRAG** — graph plus vector retrieval for AI.
- **Graph Studio** — the dashboard for exploring graphs.
- **Type A/B/C** — UI page types: Settings/Form, Data, Canvas.
- **Base UI** — primitive UI layer; Radix is not permitted.
- **Knowledge Base / Skills / Build Prompts / AGENTS.md** — what the AI knows / how it works / what to build / rules it must obey.
